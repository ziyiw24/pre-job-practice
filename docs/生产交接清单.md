# 生产交接清单

## 仓库内已完成

- M1：mock/OpenAI-compatible 网关、LangGraph 有界修订、证据/数字确定性校验、20 段/100 题评测集。
- M2：按项目所有者要求跳过真实店长试用；Docker、Redis TaskStore、readiness 和限流已就绪。
- M3：PDF/DOCX 解析、文件安全、COS 私有存储、block/页码证据、审核页与高风险确认。
- M4：微信 code2Session + JWT、门店角色、版本化 MySQL migration、课程发布和服务端判分；答题前不下发答案。
- M5：生产配置拒绝不安全默认值，限制请求体，敏感内容仅记长度与 SHA-256，H5/weapp 可构建。

## 外部条件（不得伪造为已完成）

1. 提供真实模型 Key 后重跑评测，由店长标注答案唯一率、场景有效率和可接受率。
2. 在微信公众平台配置 AppID/Secret、request/upload/download 合法域名及隐私声明。
3. 创建 MySQL/Redis/COS，执行 `backend/sql/init_mysql.sql` 后按序执行 `backend/sql/migrations/*.sql`。
4. 设置 `APP_ENVIRONMENT=production`、`PLATFORM_STORE=mysql`、`MYSQL_CONNECT_ON_START=true`、`TRAINING_TASK_STORE=redis`、`TRAINING_DOCUMENT_STORE=cos` 及至少 32 字节 JWT secret。
5. 用真机执行弱网、切后台、登录过期、重复提交、大文件和横向越权验收，再提交微信审核。

## 已知边界

- 扫描 PDF 不做 OCR，会返回 `NO_EXTRACTABLE_TEXT`。
- 本地 memory adapter 只用于演示/测试；生产启动会拒绝这些配置。
- 线上成绩只用于学习，不代表实操上岗认证。
